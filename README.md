# 2048 · 华为云闯关

一个零依赖的单文件版 2048 游戏，纯 HTML/CSS/JavaScript 实现，适合部署到华为云开发者空间、ECS 或任意静态托管环境。

## 功能

- 4×4 棋盘，方向键 / WASD / 手机滑动操作
- 分数、最高分本地存储（localStorage）
- 方块合并动画、新游戏按钮
- 页面标题包含 2048
- 单文件 `index.html`，不引用任何外部 CDN、字体或图片

## 本地运行

```bash
python3 -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。

## 部署

本项目已部署到华为云开发者空间，并通过 DevBridge 开发隧道提供公网 HTTPS 访问地址。
